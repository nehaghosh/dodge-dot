# 🎮 Dodge Dot

A simple retro-style browser arcade game where your goal is to catch the moving dot before it escapes.

## 🕹️ How to Play

Choose your avatar, enter your player name, select a difficulty, and start playing.

**Think fast. Click faster.** Catch the dot as it moves around the arena and try to beat your high score.

## ✨ Features

* 🎮 Simple arcade-style gameplay
* 👾 Multiple player avatars
* 🏆 Score and high-score tracking
* 🔥 Combo multiplier system
* ⚡ Three difficulty levels
* ⏱️ Timed gameplay
* ⏸️ Pause and resume
* 💾 Player name, avatar, and high score saved locally
* 📱 Responsive layout for different screen sizes
* 🌐 Runs directly in the browser

## 🎯 Difficulty Modes

| Mode     |       Time | Difficulty |
| -------- | ---------: | ---------- |
| 🐢 Easy  | 75 seconds | Slow       |
| ⚡ Normal | 45 seconds | Medium     |
| 💀 Hard  | 30 seconds | Fast       |

## 🛠️ Built With

* HTML
* CSS
* JavaScript

No frameworks or external JavaScript libraries are required.

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/dodge-dot.git
```

Open the project folder and launch `index.html` in your browser.

## 🌐 Play Online

Once GitHub Pages is enabled, the game can be played directly from the browser.
